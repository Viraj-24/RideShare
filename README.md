# RideShare - Professional Ride Sharing App

RideShare is a modern, enterprise-grade Android application designed to facilitate seamless ride-sharing between riders and passengers.

## 🚀 Key Features

- **Enterprise UI**: A clean, professional design featuring high-contrast themes and elevated material components.
- **Smart Location Suggestions**: Built-in autocomplete for locations across India, with specific focus on Dakshina Kannada (Mangalore, Puttur, Bantwal, etc.) and Bengaluru.
- **Personalized Experience**: Custom sidebar (hamburger menu) that dynamically displays your profile status.
- **Role Selection**: Easily toggle between being a Rider or a Passenger.
- **Ride Matching**: Real-time matching between users traveling to the same destination.
- **Secure Authentication**: Firebase-powered login and registration.
- **Safety First**: Integrated safety guidelines for both bike and car travelers.

## 🛠️ Tech Stack

- **Language**: Java / Kotlin
- **Database**: Firebase Realtime Database
- **Storage**: Firebase Storage
- **Auth**: Firebase Authentication
- **Architecture**: Material Design 3

## 📲 Installation

You can download the latest version of the app directly from this repository:
[**Download RideShare APK**](./rideshare.apk)

1. Download the `rideshare.apk` file.
2. Transfer it to your Android device.
3. Enable "Install from Unknown Sources" in your settings.
